# Учебная практика ПП.02

**Тема:** Разработка модуля калькулятора калорий с импортом базы данных продуктов из внешнего файла данных.

**Студент:** Лаптев Василий Иванович  
**Группа:** 3ИП7-24

## Цель

Разработать модуль калькулятора калорий на Python и предусмотреть импорт базы продуктов из внешнего CSV-файла.

## Стек

- Python 3.11+
- pytest

## Структура каталогов

```
.
├── data/                 # внешние файлы данных (CSV)
├── docs/                 # ход выполнения практики
├── src/calorie_calc/     # исходный код модуля
├── tests/                # автотесты
├── requirements.txt
└── README.md
```

## Проверка каркаса

```bash
pip install -r requirements.txt
PYTHONPATH=src pytest
```

Модуль находится в разработке: день 1 — каркас проекта, без расчёта калорий и без импорта CSV.
