# Учебная практика ПП.02

**Тема:** Разработка модуля калькулятора калорий с импортом базы данных продуктов из внешнего файла данных.

**Студент:** Лаптев Василий Иванович  
**Группа:** 3ИП7-24

## Цель

Разработать модуль калькулятора калорий на Python и предусмотреть импорт базы продуктов из внешнего CSV-файла.

## Стек

- Python 3.11+
- pytest

## Структура каталогов

```
.
├── data/                 # внешние файлы данных (CSV, JSON)
├── docs/                 # ход выполнения практики
├── src/calorie_calc/     # исходный код модуля (Product, import_products, load_products, ProductCatalog, calculate_portion, save_products)
├── tests/                # автотесты
├── requirements.txt
└── README.md
```

## Проверка

```bash
pip install -r requirements.txt
PYTHONPATH=src pytest
```

Модуль находится в разработке.

- День 1 — каркас проекта.
- День 2 — модель `Product`: идентификатор, название, калорийность и БЖУ на 100 г с проверкой базовых инвариантов.
- День 3 — файл `data/products.csv` с 26 продуктами.
- День 4 — `import_products`: чтение CSV (`name`, `kcal`, `protein`, `fat`, `carbs`) в список `Product`, версия 0.4.0.
- День 5 — проверка строк CSV: некорректные строки пропускаются, ошибки накапливаются в списке; обязательные поля и числа не меньше нуля. Версия 0.5.0.
- День 6 — `ProductCatalog`: хранение продуктов и загрузка `data/products.csv` при создании каталога и при запуске модуля. Версия 0.6.0.
- День 7 — поиск продуктов по названию в `ProductCatalog`: точное совпадение и подстрока, без учёта регистра. Версия 0.7.0.
- День 8 — в `ProductCatalog` можно добавить, обновить и удалить продукт. Повтор названия без учёта регистра отклоняется. Версия 0.8.0.
- День 9 — `calculate_portion`: КБЖУ порции по массе в граммах, значения на 100 г масштабируются и округляются до двух знаков. Тот же расчёт у продукта из `ProductCatalog`. Версия 0.9.0.
- День 10 — `MealEntry`: запись рациона (продукт, масса в граммах, приём пищи), метод `nutrients()`. Версия 0.10.0.
- День 11 — `total_nutrients`: сумма КБЖУ за день по записям рациона. Версия 0.11.0.
- День 12 — консольное меню (`python -m calorie_calc`): импорт, поиск, порция, рацион. Версия 0.12.0.
- День 13 — дневная норма калорий (формула Миффлина — Сан-Жеора, `daily_norm`). Версия 0.13.0.
- День 14 — сравнение съеденного с нормой (`compare_with_norm`): остаток, перебор или «в норме». Версия 0.14.0.
- День 15 — экспорт дневного отчёта в текстовый и CSV файл (`export_report_text`, `export_report_csv`). Версия 0.15.0.
- День 16 — сводные unit-тесты моделей и расчётов (`tests/test_calculations.py`); `daily_norm` и `compare_with_norm` отклоняют бесконечность и NaN. Версия 0.16.0.
- День 17 — импорт CSV на граничных случаях: UTF-8 с BOM, разделитель «;» и десятичная запятая, пустой файл, файл не в UTF-8 (ошибка строки 1); тесты `tests/test_csv_edge_cases.py`. Версия 0.17.0.
- День 18 — импорт базы продуктов из JSON (`import_products_json`): список объектов или объект с ключом `products`, проверка полей, ошибки `JsonItemError`; файл `data/products.json` с теми же 26 продуктами. Версия 0.18.0.
- День 19 — загрузка базы по расширению файла (`load_products`): .csv или .json без учёта регистра, другое расширение — `ValueError`; `ProductCatalog` и пункт меню «Импорт» принимают CSV и JSON. Версия 0.19.0.
- День 20 — экспорт базы продуктов в CSV и JSON (`export_products_csv`, `export_products_json`, `save_products` по расширению) в тех же форматах, что читает импорт; метод `ProductCatalog.save`. Версия 0.20.0.

Запуск меню: `PYTHONPATH=src python3 -m calorie_calc`.
